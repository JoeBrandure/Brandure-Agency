## What a real piece looks like

Each published piece should carry, at minimum:

- The exact prompt or prompt set, quoted verbatim
- The market it was run in, or an explicit note that no market was applied
- Which engines were queried, on what date, in what session state
- How many times each prompt was run
- Brands named, in the order they appeared
- The domains each answer cited

## Why the method section matters

The commercial argument for AEO rests on a claim that answer engines disagree
with each other, and that the disagreement is contestable. That claim is only
worth as much as the sampling behind it.

A single run of a single prompt cannot separate a real difference between
engines from ordinary run-to-run variance. Anything published here should say
plainly how many runs it rests on, and should not present a finding drawn from
one run as though it were stable.

## Structure to follow

1. **What we asked** — the prompt set and the market.
2. **What came back** — brands and citations, per engine.
3. **What it means** — the commercial reading, kept separate from the data.
4. **Limits** — sample size, session state, model tiers, date.

Keeping section 3 separate from section 2 is deliberate. The data should stay
usable by a reader who disagrees with our interpretation of it.
